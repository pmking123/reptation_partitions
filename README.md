# Reptation Partitions
---

Computational scripts and generated summaries supporting analysis of reptating polymers and integer partitions.

## Repository structure

```text
.
├── job_scripts/       # Shell scripts for running jobs/workflows
├── python_scripts/    # Python analysis, simulation, and verification code
├── summaries/         # Generated markdown/PDF outputs from runs
└── MANIFEST.md        # Verification/audit manifest linking claims to scripts/logs
```

## Quick start

1. Review `MANIFEST.md` for the verification map.
2. Run workflows from `job_scripts/` (or directly execute matching scripts in `python_scripts/`).
3. Check outputs in `summaries/`.
